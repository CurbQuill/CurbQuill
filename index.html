CSV format

Use UTF-8, a header row, dates as YYYY-MM-DD, and positive USD amounts such as 35.00. Map a platform and a type, or supply defaults. Use a reference for every row or give the file a stable batch reference.

Types are income, expense, and payout. A whole-book export includes all three types. Filtered exports include the visible transaction scope across all pages. Use an encrypted backup to preserve payout links, history, and settings.

For the verified native synthetic CSV, the original columns are recognized. Set a platform label for the imported records.
